 Student Management System

 Project Overview

The Student Management System is a Vue.js application that allows users to manage student records.

The system provides basic CRUD functionality for adding, viewing, editing, and deleting student records. It also includes search functionality and stores student data using browser localStorage.

 Features

- Add Student
- Edit Student
- Delete Student
- Search Student
- Student ID validation
- Full Name validation
- localStorage data persistence
- Success and error messages
- Responsive user interface

 Technology Stack

- Vue.js
- Vite
- JavaScript
- Tailwind CSS
- localStorage
- Vitest
- Git and GitHub
- GitHub Actions
